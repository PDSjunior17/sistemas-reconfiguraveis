# sistemas-reconfiguraveis
Repositório de exercícios e trabalhos, em VHDL da disciplina Sistemas Reconfiguraveis.

## Instruções para criar um projeto no software Quartus
1. No menu “File”, selecionar a opção “New
Project Wizard...”
2. Na página 1, no primeiro campo, digitar o
nome da pasta do projeto ou, usando o
botão apontar para a pasta do projeto;
3. no segundo campo, digitar o nome do
projeto. Vamos usar também o nome
“Cap2ex1” para o projeto;
4. o terceiro campo será preenchido
automaticamente, com o nome do arquivo
topo da hierarquia do projeto.
6. Na página 2 é solicitado o nome de outros
arquivos que fazem parte do projeto. Esse
exercício é feito com apenas um arquivo de
design entry, ou seja, não é um projeto
hierárquico. Portanto, clicar em “Next”.
7. Na página 3 deve ser configurado o
dispositivo alvo para a compilação:
• Family: Cyclone II
• Package: FBGA
• Pin count: 672
• Speed grade: 6
• Device: EP2C35F672C6 (é o primeiro da lista)
8. Na página 4 não há o que configurar para
esse exercício e a página 5 é apenas um
resumo. Então, para encerrar, clicar em
“Finish”.
